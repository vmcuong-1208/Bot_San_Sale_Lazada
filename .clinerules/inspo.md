# Inspo UI Design Mode (Nutlope/inspo)

Khi phát triển giao diện (Streamlit Dashboard, Web UI, CSS, Components) hoặc khi người dùng yêu cầu với từ khóa `inspo`:

1. **Mục tiêu:**
   - Vượt qua các thiết kế giao diện AI rập khuôn (generic dark mode, neon glow, font Inter đơn điệu).
   - Truy vấn cảm hứng thiết kế từ kho lưu trữ của hơn 800+ website thực tế qua **Inspo MCP Server** (`https://inspomcp.dev/api/mcp`).

2. **Cách công cụ Inspo hoạt động:**
   - **`recommend(brief)`**: Đưa brief mô tả ứng dụng vào để lấy trọn bộ Design Tokens (bảng màu, font chữ, layout macrostructure, spacing).
   - **`search_inspiration(query)`**: Tìm các mẫu layout (Dashboard, Product Cards, Alert Banners, Filter Bar).
   - **`find_similar(url)`**: Tìm website thực tế có phong cách tương tự.

3. **Áp dụng vào dự án:**
   - Tuân thủ thiết kế hiện đại, sạch sẽ, typography có chiều sâu và bảng màu chuyên nghiệp.
   - Kết hợp với triết lý **Ponytail**: UI đẹp nhưng code CSS/HTML tinh giản, nhẹ và tái sử dụng tối đa.
